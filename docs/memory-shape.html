The Shape of Memory

Moneta's memory system as a designed product — five dimensional views

1. Depth — the drill-down axis
Every memory has a path from surface signal to raw evidence. This is the product's core promise: you can always go deeper.
The drill-down invariant (Phase T): every memory must carry a deterministic path from anchor → body → source → raw evidence
2. Lifecycle — the metabolic axis
Memories are not static. They live, strengthen, decay, and eventually retire. This is the product's relationship with time.
The Ebbinghaus model: memory is a living thing that strengthens with use and forgets when ignored
3. Authority — the supersession axis
Memories compete. When guidance changes, the old record doesn't disappear — it gets marked as superseded. Retrieval must prefer current authority.
The cp-001 pattern: when two records match a query, retrieval must prefer the current authority — not just the one with more keyword overlap
4. Layers — the cognitive architecture
Moneta is four intelligence sources unified into one memory product. Each layer answers a different question.
L3 is the product's heart. L1/L2/L4 are the surrounding intelligence that makes it useful.
5. Reinforcement — the learning axis
Memory is not a filing cabinet. It's a cognitive system that learns from use and forgets from neglect. The distinction between exposure and learning is the product's deepest design principle.
Contract 4: "Retrieval is not reinforcement." This is what makes Moneta a memory system, not a search engine.
The Product at a Glance
Five dimensions, one memory system. The product's shape is defined by how these dimensions interact.

Lifecycle — metabolism over time
