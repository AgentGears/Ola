```

Ola-only record count = 0
duplicate and malformed record counts are known
```

Use stable record IDs where available; otherwise compare SHA-256 of exact line bytes.

### Resolution policy:

```
Ola records are a verified subset of Moneta
  → moneta-wins is valid

Any Ola-only records exist
  → preserve them
  → perform an explicit deterministic union/import
  → record the merge in the migration manifest
  → do not discard the Ola file
```

This follows the governing rule: divergent stores hard-block until conflict resolution is explicit and verified.

## Execute Externally

### Automated script (recommended)

A PowerShell script automates the entire relocation: `relocate-to-ola.ps1`

**Step 1: Copy the script OUTSIDE the workspace** (it can't rename a directory it's running inside):

```powershell
Copy-Item "C:\Next-Era\Moneta\relocate-to-ola.ps1" "C:\Next-Era\relocate-to-ola.ps1"
```

**Step 2: Close ZCode completely.** The script will refuse to run if ZCode is still running.

**Step 3: Dry run** (shows what would happen, changes nothing):

```powershell
cd C:\Next-Era
powershell -ExecutionPolicy Bypass -File relocate-to-ola.ps1 -DryRun
```

**Step 4: Execute** (after dry run confirms plan is correct):

```powershell
powershell -ExecutionPolicy Bypass -File relocate-to-ola.ps1 -Execute
```

The script performs: pre-flight validation → process quiescence check → config backup → workspace backup (with file-count verification) → rename → config update (with JSON validation) → rollback instructions.

**Step 5: Start ZCode from the new path, then verify:**

```powershell
powershell -ExecutionPolicy Bypass -File relocate-to-ola.ps1 -Verify
```

Verification uses temporary data roots (`$TEMP/ola-r15-verify-*`) to avoid contaminating `~/.ola/`. It checks: test suite (20/20), plugin name (`ola`), MCP server key (`ola`), no old-root references in active code, hooks.json path resolution, hook failure log.

### Manual alternative

If you prefer to run the steps manually, the script documents each operation. The key steps in order:

1. Stop ZCode and all Node processes referencing `C:\Next-Era\Moneta`
2. Backup ZCode config: `Copy-Item ~/.zcode/cli/config.json ~/.zcode/cli/config.json.bak.r15-<timestamp>`
3. Backup workspace: `Copy-Item C:\Next-Era\Moneta C:\Next-Era\Moneta.r1-backup-<timestamp> -Recurse`
4. Verify backup file count matches source
5. Rename: `Rename-Item C:\Next-Era\Moneta Ola`
6. Update config: plugins.dirs `C:\Next-Era\Moneta` → `C:\Next-Era\Ola`, enabledPlugins `moneta@inline` → `ola@inline`
7. Validate config JSON
8. Confirm no old-root references remain in config
